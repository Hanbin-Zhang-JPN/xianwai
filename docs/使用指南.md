# 弦外使用指南

适用于 0.7.3。当前日常使用方式是 **Mac 弦外 + iPhone Safari**。只会分析你主动导入的内容，不能直接读取微信，也不能修改微信的长按菜单。

## 第一次使用

1. 打开 Mac 上的弦外，等待显示“手机链接已验证”和二维码。Mac 需保持开机联网。
2. 用 iPhone 相机扫描二维码，在 **Safari** 打开并确认连接。保留“记住 Mac 连接”和“保留聊天与收藏”，方便跨天继续。
3. 在“联系人与文件夹”新建联系人；一个人始终使用同一个入口，可按“相亲认识”“朋友”等分类。
4. 点“编辑对话与说话习惯”，填写已知背景。例如：“相亲认识两个月，见过两次，尚未确认恋爱关系；我平时表达简短，不用亲昵称呼。”把事实和猜测分开。

Mac 关窗口后仍在后台运行；合盖、断网或退出应用会中断连接。Mac 重启或点击“重新连接”后，手机地址可能改变，需要扫描新二维码。旧主屏幕入口不会自动更新。

## 已经聊了很久，怎么带入旧记录

在该联系人下选择“导入聊天”，从最早到最新分批追加。可以粘贴文字、选择 TXT / 消息 JSON，或导入微信截图。

文字格式示例（虚构）：

```text
我：周末想去看展，你有兴趣吗？
对方：可以呀，不过我周六上午有事。
我：那我们再商量下午的时间。
```

没有发送者标记的行暂记为“对方”，需要你核对。多行消息可使用 JSON，以免换行被误识别为另一条消息。有原始发言时间时，JSON 可以保留日期：

```json
[
  {"role":"me","text":"周末想去看展，你有兴趣吗？","sentAt":"2026-11-02T19:30:00+09:00"},
  {"role":"partner","text":"可以呀，不过我周六上午有事。","sentAt":"2026-11-02T19:31:00+09:00"}
]
```

`me` 是你，`partner` 是对方。`sentAt` 可省略；未知就保持未知，不要用导入日期代替。日期可用带时区的 ISO 字符串或毫秒时间戳。

核对页请检查双方、文字、日期、顺序和截图重叠。保持“接着当前对话”勾选，才会追加。只有边界上发送者、文字、已知发言时间都一致的较长连续片段才会自动合并；时间未知的重复对话仍可能难以区分，不确定时取消“合并完全重叠的消息”。

- 文字每批最多 10000 条、200 万字；文件最多 8 MB。
- 截图每批最多 12 张、300 条；识别后仍需核对。
- 每位联系人总计最多 10000 条当前消息、100 条分析；资料库总计最多 32 MB。达到容量会提示，不会静默截断。

核对后选择“保存并梳理整段历史”，再确认开始。它会把**全部已导入文字和关系背景**分段通过 Codex 发送给 OpenAI，形成有原话引用的关系档案。Mac 保持运行时，可以离开手机页面，回来继续查看进度；失败或停止后可复用已完成分段。

查看档案时，逐项看原话、其他解释和未知事项。重要约定可以在“长期聊天与前情”中标记，过期后取消。新增重要进展后更新档案；旧版缺少原文校验的档案需要重新梳理。

## 每天怎么用

1. 选择同一个联系人，把对方新消息粘贴到下方，确认发送者是“对方”，点“帮我回”。有连续的新消息时可一起导入，避免只带最后半句话。
2. 涉及时间、地点、是否有空或承诺时，展开“换个方向，按我的实际情况起草”，填真实情况，再点重新起草。例如：“我还在开会，预计十点结束，今晚不能见面；想另约时间。”
3. 查看推荐草稿和单独核对提示。可切换三种语气、自己编辑。主动“重新起草”会发起新生成与核对；成功后另存一条，保留旧稿。
4. 确认事实、时间、承诺和语气符合自己，再复制到微信发送。“待补充”未填好时不能复制；有疑点、编辑后、跨天或较早的建议，需要再次核对。
5. **实际在微信发出后**，回弦外点“我已发出”，补入后续语境。如果在微信改过字，先把工具草稿改成实际发出的内容再记录。误记可撤销。
6. 第二天继续选择这位联系人，追加新消息。可在“分析记录”搜索旧稿，查看当时真正参考过的原文。

普通回复最多选入 300 条、8 万字，结合近期、相关旧原话、长期标记和可用档案；页面显示实际参考范围。它不等于每次都把所有历史重新读一遍。心理解释始终是待确认的推测，单独核对也可能遗漏问题。

## 保存、导出与恢复

- 在“设置与隐私”确认保存已开启；配对后会同时尝试备份到 Mac。留意本机空间不足、Mac 备份失败或冲突提示。
- 在“联系人与文件夹”可导出完整资料库，或在联系人设置中导出单人资料，保留原文、分析和草稿。文件包含私人聊天，请自行妥善存放。
- **当前跨设备自动恢复依靠已配对 Mac 的备份。**导出的完整资料库 / 联系人资料供保留和查阅，目前不能通过普通“导入聊天”入口完整恢复；该入口只接收文字或消息数组。
- 重连出现冲突副本时，两份记录都保留，请核对后继续。不要通过“清除资料库”解决扫码或网络问题。

## 常见问题

**扫码打不开 / 凭证过期**：确认 Mac 仍运行，等待“手机链接已验证”。必要时点“重新连接”，扫描新二维码并用 Safari 打开。

**重新起草失败 / 一直等待**：检查 Mac 网络、Codex 登录状态及可用额度。回复先生成再单独核对，需要额外等待。核对失败不会把新稿当成可直接使用的结果；保留原稿时会明确提示。

**看见“本地规则试用”**：尚未使用真实模型。连接 Mac 并开启在线 AI 后，再重新分析。

**内容没保存**：查看保存开关和页面错误；先导出目前仍能看到的资料，再排查连接或浏览器空间。若提示原始记录损坏，先下载原始备份，不要立即清除。

**担心模型猜错她的意思**：先看原话和替代解释，补充你知道的实际情况。不要把模型推测写进关系背景当作事实；需要确认的事，优先自然地向本人确认。
